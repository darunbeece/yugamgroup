What does this test for? ▼
Our scanner checks for:

  • HTTP Security Headers - Content-Security-Policy, X-Frame-Options, HSTS, etc.
  • Server Information Disclosure - Exposed server banners and version info
  • Common Vulnerabilities - Known security issues and misconfigurations
  • DNS Security - SPF, DKIM, DMARC record validation
  • Open Ports & Services - Exposed services and their versions
  • Technology Stack Detection - Identified frameworks and libraries
